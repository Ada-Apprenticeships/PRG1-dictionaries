# PRG1: Dictionaries (PRIM activities)

Day 6. Seven activities plus two stretch folders, each in its own folder, each
with the code and its tasks together in one place.

## PRIM

Every activity follows the same four steps, in this order:

| Step | What you do |
|---|---|
| **Predict** | Say what the code will do **before** you run it. Write it down. |
| **Run** | Run it. Compare against your prediction. |
| **Investigate** | Work out *why* it behaves that way. |
| **Modify** | Change something specific, predicting the effect before each change. |

Getting a prediction wrong and working out why is worth more than getting it
right. Most of what you will do professionally is read code, work out what it
does, and change it without breaking it. That is what these four steps rehearse.

## The activities

### Morning: reading dictionaries

| Folder | Focus |
|---|---|
| `activity-1-grades-lookup/` | Getting something out, and what happens when it is not there |
| `activity-2-values-that-are-lists/` | When the value is a list rather than a single number |
| `activity-3-loyalty-points/` | A working program: building and updating a dictionary as it goes |
| `activity-4-broken-dictionaries/` | Three faults in code that runs perfectly happily |

### Afternoon: extending a real program

| Folder | Focus |
|---|---|
| `activity-5-reading-the-analyser/` | A working log analyser: how it does what it does |
| `activity-6-extending-the-analyser/` | Two functions missing, docstrings as the specification |
| `activity-7-broken-analyser/` | The same analyser with three faults, none of which crash |

Activity 6 is deliberately the same shape as the assignment task released this
afternoon. Activity 7 is the one to reach if you can.

### Stretch

| Folder | Focus |
|---|---|
| `stretch-1-nested-dictionaries/` | Dictionaries whose values are dictionaries |
| `stretch-2-ranking-by-value/` | Turning counts into a ranked report |

Stretch folders are optional and come after the core activities, not instead of
them. Activity 6 also carries an optional extension at the end.

## How to work through these

Work in pairs. One of you drives, the other questions and challenges, then swap
at each new activity.

You are **not** expected to finish everything. Depending on your experience you
might spend a whole session on the first two. **That is fine.** What is not fine
is running the code before predicting, or reaching Modify without being able to
explain what the original did.

## Running a file

Open the repository in a Codespace, then in the terminal:

```
python activity-1-grades-lookup/grades_lookup.py
```

If `python` is not recognised, use `python3` instead.
